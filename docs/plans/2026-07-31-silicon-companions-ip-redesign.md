# 硅灵伙伴：盲盒形象 IP 重设计

日期：2026-07-31

## 目标

把现有“同一圆角底板里的像素图标”升级成一套能长期扩展、在 48px 头像中也能被认出的收藏角色。

这套角色不复刻任何现成潮玩 IP。它只借鉴成熟盲盒产品的通用方法：固定母体、鲜明轮廓、系列叙事、材质差异和隐藏款惊喜。

## 母体角色：硅灵伙伴

所有角色共享以下不可变 DNA：

- 头部约占全身高度 58%，身体为柔软豆形。
- 一对像素显示眼，不使用复杂五官。
- 头顶都有一枚“信号芽”：短天线末端是一颗发光圆角像素。
- 小手像软手套，脚短且略向外张。
- 主体采用奶白软胶色，系列身份由轮廓、道具和两种以内的强调色表达。
- 角色必须在纯黑剪影下仍能互相区分，不能只依赖换色。

## 造型层级

每个角色必须同时具备三层辨识：

1. **远看轮廓**：帽檐、耳朵、披风、背壳、头冠或尾巴形成唯一外轮廓。
2. **中看姿态**：抱、举、探、蜷、飞、回望等姿态不能重复。
3. **近看收藏细节**：缝线、软绒、半透明糖果树脂、磨砂软胶或珠光颗粒。

头像缩小到 48px 后，第一层和第二层仍需成立；第三层只服务大图和开盒时刻。

## 稀有度不是换色

- **N**：完整母体 + 单一轮廓道具；主要为磨砂软胶。
- **R**：新增外套层或可读姿态；至少一种软绒/纸纹/金属小件。
- **SR**：改变整体剪影；加入背壳、透明头盔或环形尾巴。
- **SSR**：改变材质与空间关系；使用半透明身体、悬浮伴生物或环绕结构。

禁止仅通过金色边框、彩虹滤镜、换色来表示 SR/SSR。

## 首发系列叙事

系列名：**第一次收到信号**

设定：十四个硅灵在不同频段第一次听见人类世界。它们不是战斗职业，而是以自己的方式回应信号：照亮、记录、安抚、探索、怀疑、守护和创作。

每个角色的盲盒卡面只写一句“收到的第一条信号”，让形象、签名和主页背景共享同一故事来源。

## 视觉验收

- 14 个角色拼成黑色剪影后，至少 12 个能被无文字认出。
- 缩小到 48×48 时，眼睛、信号芽和主轮廓仍清楚。
- 不把圆角方框画进角色图片；卡片背景由网站 UI 承担。
- 同一角色在头像、主页大图、开盒动画中使用同一主形象。
- 不出现阴暗赛博装甲、攻击性武器、惊悚五官或廉价霓虹描边。
- 不出现已有潮玩品牌的脸型、牙齿、耳朵、服饰或标志性构图。

## 资产生产

1. 先生成 14 角色母版设定图，确认母体比例与剪影。
2. 按角色单独生成正面三分之四全身图。
3. 为透明素材生成纯色键控背景并本地抠图。
4. 每张图人工检查边缘、手脚数量、信号芽一致性和小尺寸可读性。
5. 输出 512×512 PNG；站内头像按 128、64、48 三档验证。
6. 只有通过验收的整套资产才替换生产图，不混用新旧画风。
